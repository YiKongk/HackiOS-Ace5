# 功能状态与验证边界

记录对象：OnePlus Ace 5 PKG110 / giulia，SM8650，Adreno 750v2（芯片 ID `0x43051401`），Synaptics S3910。原 Android 环境为 Android 16、KernelSU root。以下是真机基线的历史结果；整理后的公开源码本次做了哪些检查，见[发布记录](RELEASE.zh-CN.md)。

## 硬件与系统

| 项目 | 证据 / 当前边界 |
| --- | --- |
| UEFI、XNU、iOS 16.5 | 可到锁屏和桌面；有限时长 RAM 会话，退出返回 loader |
| 触摸 | 已收到真实 S3910 报告，用户确认“触摸正常，位置准确”；多指与长时间覆盖有限 |
| CPU | 仅一个 XNU 核心；`--bootcpu 1` 留 CPU 0 观察 USB；不声明多核可用 |
| GPU 初始化 | GMU、ZAP、SMMU、直接 CP 队列、fence 和渲染已验证 |
| UI 合成与送屏 | Mesa Freedreno 的 FD750，GPU 缩放、清除和面板缓冲写入已验证 |
| Metal | 部分 compute、fragment、索引/深度、drawable 与 CAMetalLayer；非完整兼容层 |
| 默认壁纸 | 15 个图层本地转 PNG，保留 CAML；尺寸、alpha 和 sRGB 像素对比匹配 |
| Wi‑Fi | 未适配；能打开某个设置页面不等于可联网 |
| 蓝牙、蜂窝、音频、相机、充电管理 | 未完成 Ace 5 适配，不用 redwood 的状态代替 |
| 持久化安装 | 本版本不提供；设备系统分区没有在这些验证中刷写 |

面板缓冲为 1264×2780，stride 5056；iOS 的渲染尺寸是 1125×2436。GPU 对输出做缩放。GPU 固定 231 MHz，无完整 DVFS 和原生 DPU page flip。

## GPU / Metal 实测

2026-10-23 的 10 分钟显示压力会话记录：

- 4,440 次 GPU 送屏，0 次 CPU 送屏回退，合成路径未记录 CPU 拷出。
- 600 帧 Metal 应用绘制，0 次读回失败；fence 27,777 / 27,777 完成。
- 送屏驱动阶段加权平均约 1.7789 ms；这不含整帧的应用逻辑、合成与调度。
- 像素读回覆盖恒等、最近邻/线性放大、裁剪、面板尺寸及清除等 8 种情形。
- fragment 扫描输入 271 个：263 个完成绘制，2 个不能创建 pipeline，6 个无法提供其声明的纹理；不能将 271 个全部计为支持。

测试 recipe、读回程序和判定器保留在 `tools/ace5/`。原始设备日志、截图、系统文件不公开；这里的统计是历史验证摘要，不是第三方独立复测或完整 Metal 一致性认证。

## 桌面单核优化

固定脚本交替滑动桌面和操作 Settings，对照 backboardd 的 Mesa 默认线程与 inline 命令生成：

| 指标 | 默认线程 | inline 首次 | inline 重复 |
| --- | ---: | ---: | ---: |
| 桌面面板缓冲完成次数/秒 | 51.29 | 54.30 | 53.35 |
| 桌面间隔 >25 ms 比例 | 15.10% | 9.12% | 10.61% |
| Settings 完成次数/秒 | 55.06 | 54.18 | 53.30 |

这些是日志中的缓冲完成间隔，不是相机/光学测量的真实面板刷新率。Settings 有小幅回退；桌面仍受单核 CPU 约 93–94% 占用、GPU 固定低频、CPU 缓存同步和当前显示实现限制。“GPU 在工作”和“所有动画流畅”是不同问题。

两轮均通过 8 项送屏读回、263 项 fragment 绘制和 2 次全尺寸 drawable 验证。下一步应测量 CPU、GPU 和呈现阶段各自耗时，再决定多核、频率或 DPU 的改造，不把未验证试验算作成果。

## 已知问题

- 用户曾报告桌面、Wi‑Fi 页面、飞行模式后卡死；sleepd/configd 补齐修复了一个重复的系统服务等待路径，其他死机原因仍未完全排除。
- GPU 没有完整每进程隔离和 hang recovery，异常命令可能导致 CrashDump 或 USB 消失。
- 部分 Metal API、shader/纹理格式、应用和系统服务未覆盖；不承诺 App Store/Apple ID 可用。
- RAM 会话不是日用系统；重启会丢失 RAM 文件变化。
- 本版本主动排除后续 Wi‑Fi PCIe 诊断和未经此基线实机验证的 GPU 时间戳、双核、命令环优化。

不要用一个总进度百分比替代这些功能与验证范围。
